# Reproducing Published Results

Paper-level claims are not treated as reproduced unless this repository contains
a runnable command, the required dataset, the evaluation protocol, and a
recorded result.

The currently recorded EL++ benchmark configuration and results are documented
in [`benchmarks.md`](benchmarks.md). Dataset conversion and example selection
are documented in [`../examples/README.md`](../examples/README.md).

Unit and property tests check implementation behavior and mathematical
invariants. They do not by themselves reproduce a paper's empirical result.
